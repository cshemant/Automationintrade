# Shared Market Data Cache Update

This version prevents the same stock from being downloaded repeatedly while the JSON update workflow is running.

## What changed

- Added `SharedMarketDataCache.py`.
- Daily Yahoo OHLCV data is downloaded in batches and saved temporarily under `.runtime-cache/ohlcv/`.
- Latest CMP is downloaded separately in 5-minute Yahoo batches and saved under `.runtime-cache/latest-quotes/`.
- The latest completed trading-session row is overlaid on daily OHLCV, so a delayed daily Yahoo candle cannot keep the displayed CMP one session old.
- Volume Surge, Price Action, and Technical Analysis reuse the same cached history.
- CMP and daily change already generated by the 52-week market update are reused in Price Action, Technical Analysis, and Results JSON.
- NSE requests now use shorter timeouts and a circuit breaker. After repeated NSE failures, the run switches immediately to the shared Yahoo cache or previous JSON instead of waiting for every stock to time out.
- NiftyIndices constituent downloads also use a circuit breaker and fall back to existing JSON symbol lists.
- The duplicate sector-page generation step was removed from `UpdateAllData.py`.
- GitHub Actions timeout was increased from 90 to 120 minutes as an additional safety margin.

## Normal command

```bash
python UpdateAllData.py --mode all --batch-size 80
```

No new package is required. The existing `requirements.txt` already contains pandas and yfinance.

## Cache behavior

- GitHub Actions: the cache is created once during the workflow and reused by later scripts in that same run.
- Local machine: daily OHLCV can be reused for up to 8 hours, while latest-price quotes refresh after 30 minutes.
- The cache is ignored by Git and is not committed to the repository.

## First V165 verification

Delete the old temporary cache once before the first test:

```bash
rm -rf .runtime-cache
python GenerateMarketToolsJson.py --mode 52w --index nifty-pharma
```

On Windows Git Bash, the same command works. In PowerShell use:

```powershell
Remove-Item .runtime-cache -Recurse -Force -ErrorAction SilentlyContinue
python GenerateMarketToolsJson.py --mode 52w --index nifty-pharma
```

Open `market-data/52-week-high-low/nifty-pharma.json` and verify that `ABBOTINDIA` contains a recent `marketDate` and the source `Yahoo Latest Quote + Daily History` when NSE is unavailable.
